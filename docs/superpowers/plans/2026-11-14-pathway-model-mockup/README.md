# Pathway model mockup

Three artboards of the model page, drawn before the implementation, in the Design canvas
format (`.dc.html`; `canvas.json` is the index): the evaluation of one synthetic profile
(`Main.dc.html`), the model card (`Model.dc.html`) and the population view
(`Population.dc.html`). Every number on them is illustrative. The built pages are under
`services/frontend/src/routes/projects/$projectId/models/`.
