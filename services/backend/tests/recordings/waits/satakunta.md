# Hoitoonpääsy sote-palveluissa
Hyvinvointialueiden järjestämän perusterveydenhuollon kiireettömään hoitoon pääsyn enimmäisajoista säädetään terveydenhuoltolaissa (1326/2010). Hoitoonpääsyn enimmäisajat ovat 1.1.2025 voimaantulleiden säädösmuutosten myötä eri pituiset 23 vuotta täyttäneillä ja tätä nuoremmilla.
